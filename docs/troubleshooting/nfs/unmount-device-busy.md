# NFS 卸载时报 `device is busy`

## 现象

- 执行 `umount /mnt/nfs` 返回 `device is busy`。
- 发布、维护或重挂载操作被阻塞。

## 影响范围与环境

- 适用于 Linux NFS 客户端卸载共享目录的场景。
- 常见原因是目录仍被进程占用、Shell 当前工作目录未退出，或有后台任务持续访问挂载点。

## 排查步骤

1. 查找占用进程。

```bash
sudo lsof +D /mnt/nfs
sudo fuser -vm /mnt/nfs
```

2. 检查当前 Shell 或服务的工作目录是否仍在挂载点内。

```bash
pwd
ps -ef | grep /mnt/nfs
```

3. 如果是容器或守护进程占用，先确认所属服务，再决定是否停止。

## 修复步骤

1. 优先优雅停止占用进程或切换工作目录。
2. 再次尝试正常卸载。

```bash
sudo umount /mnt/nfs
```

3. 如果必须尽快释放挂载点，可使用懒卸载。

```bash
sudo umount -lf /mnt/nfs
```

## 验证恢复

1. 确认挂载点已经消失。

```bash
mount | grep /mnt/nfs
```

2. 检查相关发布或维护动作是否已继续执行。
3. 如后续需要重新挂载，验证新挂载可读写。

## 注意事项

- `umount -lf` 适合应急，但不应代替常规处理。
- 对生产服务先确认进程归属，避免误杀关键业务。
- 如果频繁出现该问题，应补充服务关闭顺序和挂载点使用规范。

## 回滚方案

- 如卸载后发现业务仍需访问共享目录，按原挂载参数重新挂载。
- 若使用了懒卸载导致状态不一致，先确认相关进程退出，再执行标准挂载流程恢复。
