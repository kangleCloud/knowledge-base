# Backend

## 适用场景

面向后端开发、服务治理和组件接入，收敛基础知识、框架说明、编码规范与工程实践。

## 推荐入口

- Java 基础：`JVM`、`Spring Boot Bean 生命周期`
- 框架与组件：`MyBatis`、`Spring Boot 注解`、`Spring Boot 安全`、`Excel 示例`
- 中间件接入：`Redis`、`Redisson`、`MinIO`、`Sentinel`
- 开发实践：`分布式锁`、`高并发设计`、`请求校验注解`、`RabbitMQ 使用规约`、`OpenResty 灰度`

## 使用说明

- 开发向文档优先说明适用场景、接入方式、示例代码与注意事项。
- 如涉及基础设施部署、集群运维或故障恢复，优先放到 `database/`、`middleware/`、`devops/` 或 `troubleshooting/`。

## 注意事项

- 示例代码中的账号、密码、Token 与密钥必须使用占位符。
- 历史实践稿、资源清单和不再维护的草稿默认进入 `archive/`，不进入主导航。
