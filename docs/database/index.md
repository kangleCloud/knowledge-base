# Database

## 适用场景

面向数据库安装、基础操作、规范治理、集群、高可用、备份恢复与运维排障。

## 推荐入口

- MySQL：安装部署、基础操作、设计规范、组复制、双主双从、XtraBackup
- MongoDB：6.0 与 7.0 安装部署
- 达梦：基础操作与使用说明
- Hive：常用 SQL

## 文档约定

- 安装、集群、备份类文档应包含适用版本、环境要求、步骤、验证方式、常见问题和回滚说明。
- 规范类文档应包含适用范围、示例和落地建议。

## 注意事项

- 过期但仍具历史兼容价值的数据库文档会转入 `archive/`，例如不再推荐的新环境版本。
- 真实密码、复制账号口令、备份账号等必须统一替换为占位符。
