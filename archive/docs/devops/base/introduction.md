# Java介绍

Java 有两种不同的实现，OpenJDK 和 Oracle Java。它们大部分都相同，除了 Oracle Java 拥有一些额外的商业特性。OpenJDK 是 Java 平台的开源实现。

到目前为止，JDK 存在了三个版本的长期支持版，分别是 JDK8、JDK11 和 JDK17。<font color="red"><b>业务开发中，团队约定使用 JDK8</b></font>，基于 Java 环境运行的软件（如 Jenkins）应安装其需要的 JDK 版本。

Java 8 是于2014年3月14号发布。从Java 8开始开发代号已经弃用了，所以从Java 8 之后已经没有官方的开发代号了。Java 8u201/202 是最后一个免费的 Oracle JDK 8 版本，Oracle 于 2019-01-15 停止免费商用更新。
